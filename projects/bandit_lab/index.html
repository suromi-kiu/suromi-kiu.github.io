How to establish a ssh connection

We can use the command ssh to establish a connection, in order to make a connection between our machine and bandit, we have to use the port 2220. Check the following example

terminal 

# Use: ssh user@server -p 2220 (-p is the port in which we are going to stablish the connection)
ssh bandit0@bandit.labs.overthewire.org -p 2220

If you want a way to make a ssh connection that provides you more options such as, providing password or sending commands, you can use sshpass instead of ssh. Check the example

terminal 

sshpass -p "PASSWORD" ssh bandit0@bandit.labs.overthewire.org -p 2220 

# if you want to send a command you have to include the command at the end of the sentence, EX:
sshpass -p "PASSWORD" ssh bandit0@bandit.labs.overthewire.org -p 2220 "whoami"

Another way is using my script providing the user and the password, you can get it by cloning Bash functions

terminal 

# First we have to clone the repository
git clone https://github.com/suromi-kiu/Bash_functions.git

# Then go inside the directory called Bash_functions and search the script called 'bandit_connection.sh', Check the example
./bandit_connection.sh USER PASSWORD

# Another example to make the process clear (The password of the user bandit0 is bandit0 :) )
./bandit_connection.sh bandit0 bandit0
