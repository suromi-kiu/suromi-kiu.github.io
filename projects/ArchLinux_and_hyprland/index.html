> Installing ArchLinux + hyprland

In this Guide we will install hyprland as our WM on ArchLinux, we also going to use me Hypr-dotfiles, enjoy it.



Installation

Before Installing hyprland, you should Install an basic Archlinux system, you can use an installation guide by clicking the following link ArchLinux_Installation

First we have to install some packages that are important

terminal 

sudo pacman -S hyprland waybar kitty dunst hyprpaper xdg-desktop-portal-hyprlan sddm

After installing all the packages, we can start hyprland by typing hyprland, but before starting hyprland, we need to enable the sddm service

terminal 

sudo systemctl enable sddm

You can Install a new theme for sddm, I will install the sddm astronaut theme

terminal 

sudo pacman -S sddm-astronaut-theme

We need to configure the sddm.conf and add "sddm-astronaut-theme" in the '[theme] current=' section

terminal 

# If you do not have the .config file, you can create it by doing the following command
sddm --example-config
# Then open the config file, it is commonly located in /etc/sddm.conf
nvim /etc/sddm.conf
